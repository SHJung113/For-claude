# 20단계 커리큘럼 & 콘텐츠 확보 체계

> 상위 문서: [PLAN.md](./PLAN.md) · 버전 v0.3 · 2026-11-20

## 1. 설계 원칙

- **성장 서사**: 미국 아이가 유치원에서 대학생이 되기까지 실제로 듣게 되는 말을 순서대로 따라간다.
- **두 개의 트랙**: 모든 단계에 **일상 대화(Daily)**와 **뉴스(News)** 트랙이 함께 있다.
- **"거의 안 들리는" 출발점**: L1은 느리고 또렷한 발음, 짧은 문장으로 시작한다. 연음은 단계마다 조금씩 더한다.
- **성인 학습자 빠른 진급**: 사용자는 성인이라 읽기 어휘는 이미 높을 가능성이 크다. 그래서 진급 기준은 *소리 인식 정확도*로만 판단하고, 쉬운 단계는 빠르게 통과할 수 있게 한다(§4).

## 2. 20단계 정의

> wpm = 분당 단어 수. 참고로 원어민 일상 대화는 대략 150~190wpm, 방송 뉴스는 대략 160~180wpm이다.

## 3. 콘텐츠 확보 체계 ("계속 확보"를 위한 구조)

### 3.1 세 가지 콘텐츠 소스
| 소스 | 트랙 | 설명 |
|---|---|---|
| **① 성장 시리즈 (오리지널)** | Daily | 직접 만든 가상 인물(예: 주인공 *Max*와 가족·친구)이 L1에서 L20까지 함께 자란다. 같은 인물이 계속 나와서 맥락이 쌓이고 흥미가 유지된다. 단계마다 에피소드를 계속 추가할 수 있다. |
| **② 상시 뉴스 (Evergreen)** | News | 동물·우주·역사·과학처럼 시간이 지나도 낡지 않는 주제를 뉴스 형식으로 쓴다. 주제가 사실상 무한하다. |
| **③ 시사 뉴스 (재작성)** | News | 미국 정부 기관 보도자료처럼 퍼블릭 도메인인 1차 자료의 **사실만** 가져와서, 단계에 맞는 문장으로 새로 쓴다. L15부터는 라이선스를 확인한 실제 음성 자료도 화이트리스트로 섞는다. |

### 3.2 주제 매트릭스
`단계(20) × 주제 영역(유치원 20개 ~ 대학 40개) × 형식(대화/독백/인터뷰/리포트)` 표를 관리한다. 비어 있는 칸부터 우선 생성해서 내용이 한쪽으로 쏠리거나 반복되지 않게 한다.

### 3.3 생성 파이프라인
```
levels/L07.yaml (속도·어휘 목록·문장 길이·허용 연음·화자 수·주제 목록)
  → ① 스크립트 생성: 단계 사양 + 성장 시리즈 설정(인물·지난 줄거리) + 매트릭스의 빈 칸
  → ② 자동 품질 검사
       - 어휘 범위: 95% 이상이 해당 단계 어휘 목록 안 (벗어나는 단어는 주석 처리)
       - 문장 길이와 연음 특성이 사양과 맞는지
       - 기존 콘텐츠와 겹치는지 (n-gram 유사도)
       - 자연스러움·연령 적합성 검토 (LLM 2차 검수)
  → ③ TTS 합성: 단계별 화자 목록에서 배정, 목표 wpm에 맞춰 속도 설정
  → ④ 정렬: 문장·단어 타임스탬프 생성 (강제 정렬)
  → ⑤ 실측 검사: 실제 wpm과 클립 길이 확인, 벗어나면 재합성
  → ⑥ 번들 생성: content.json + audio.m4a → catalog.json 갱신
```

### 3.4 공급 주기
- **소비량 기준**: 하루 1시간이면 새 콘텐츠를 하루 3~4개, **주당 약 25개** 쓴다.
- **초기 시드**: L1~L5는 단계당 30개(Daily 20 + News 10) = 150개를 M1에서 만든다. L6~L20은 단계당 15개를 M3에서 만든다.
- **지속 보충**: 사용자의 **현재 단계 ±1**에 주당 25~30개를 공급한다. 남은 미학습 콘텐츠가 2주치(약 50개) 아래로 떨어지면 생성을 실행한다.
- **생성 비용**: Kokoro는 이 환경의 CPU에서 돌아가며 비용이 0원이다. 1분 길이 클립 하나에 수십 초 정도 걸린다.
- **변형 재사용**: 같은 스크립트를 다른 목소리나 억양으로 다시 합성한 버전을 둔다. 원문은 같아도 다른 소리로 들을 수 있어서, 듣기 노출을 늘리는 비용이 적다.
- 실행 방식은 두 가지 중 고른다. ⓐ 필요할 때 Claude 세션에서 `tools/contentgen` CLI를 실행 ⓑ 예약 작업으로 매주 자동 실행

### 3.5 어휘 기준 자료 (라이선스는 M0에서 확인)
- 유치원~초등: Dolch, Fry 시각 어휘(sight words) 목록
- 그 이상: 일반 빈도 기반 어휘 목록. 공개 라이선스인 목록을 쓰고 출처를 기록한다.

## 4. 레벨 배치와 진급 규칙

- **배치 테스트**: L1, L3, L6, L9, L12, L15, L18에서 문장 3개씩 받아쓰기를 해서 시작 단계를 정한다. 안 들리면 L1부터 시작한다.
- **진급**: 1.0x 속도에서 받아쓰기 정확도 **85% 이상을 연속 3개 콘텐츠**에서 달성하면 다음 단계로 올라간다.
- **빠른 진급**: 정확도 95% 이상이면 한 단계를 건너뛸 수 있다고 안내한다.
- **보충**: 연속 3개가 60% 미만이면 이전 단계 복습을 권한다. 강제로 내리지는 않는다.
- **목표 구간**: 학습 중 정확도 70~85%를 유지하도록 다음 콘텐츠를 추천한다. 너무 쉬워도, 너무 어려워도 효과가 떨어진다.
