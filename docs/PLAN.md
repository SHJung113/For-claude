## 변경 이력
- **v0.4**: 첫 사용 피드백을 반영해 재계획.
  - 사용 상황 = **주로 폰, 이동 중**
  - 기능 우선순위 = **반복 재생 설정 → 받아쓰기·채점 → 단어·표현장·복습**
  - 콘텐츠 문제 = 양 부족, 너무 짧음, 음성 부자연스러움
  - **YouTube 연동 추가**: 앱 안 플레이어로 재생(B) + YouTube를 참고해 대본 새로 쓰기(C). 대상 채널은 *Easy English* (@easyenglish551)
  - 디자인은 휠 중심에서 **터치 중심 최신 디자인**으로 재설계
- v0.3: 무료 TTS(Kokoro), 하루 1시간 학습, 주당 1시간 테스트, Android + Windows 확정. CI로 APK와 Windows zip 배포.
- v0.2: 개인용, 20단계 커리큘럼(미국 유치원 → 대학), Flutter, 휠 UI.

## 3. 해결안 (SOLVE)

### P1. 디자인 재설계 — 0.80
- **방향**: 휠은 기본에서 빼고, 터치 중심으로 바꾼다. Android 최신 디자인 기준(Material 3)을 바탕으로, 흑백 위주에 강조색 하나를 쓰는 단순한 톤은 유지한다.
- **이동 중 원칙**
  - 주요 버튼은 화면 아래쪽 1/3, 엄지가 닿는 영역에 크게 둔다.
  - 화면을 보지 않아도 되게 한다: **이어폰 버튼과 잠금화면에서 재생·이 문장 다시 듣기·다음 문장** 조작
  - 글씨와 버튼을 크게, 밝은 야외에서도 보이는 색 대비
- **진행 방식**: 디자인 도구 플러그인(Mobile Design System, Design)을 설치하면 그 도구로, 아니면 직접 만든 웹 시안으로 핵심 화면 3개를 먼저 보여드린다. 핵심 화면은 듣기, 받아쓰기, 단어장. 고르시면 그 시안으로 앱을 다시 만든다.
- 휠은 설정에서 켜는 "클래식 모드"로 남길지 시안 확인 후 결정한다.

### P2. 반복 재생 설정 — 0.85 (1순위)
| 설정 | 선택지 |
|---|---|
| 문장마다 반복 횟수 | 1 / 2 / 3 / 5회 / 무한 |
| 문장 사이 멈춤 | 0 / 1 / 2 / 3초, 또는 "문장 길이만큼" (따라 말할 시간) |
| 재생 범위 | 한 문장 / 처음부터 끝까지 / A–B 구간 |
| 속도 | 0.5–1.5x (피치 유지) |
| 백그라운드 | 화면이 꺼지거나 다른 앱을 써도 계속 재생, 잠금화면·이어폰으로 조작 |

### P3. 받아쓰기 + 채점 — 0.85 (2순위)
- 문장을 듣고 입력하면, 단어마다 **맞음 / 틀림 / 빠짐 / 추가** 를 표시한다.
- 틀린 이유를 분류한다: **연음·약화**(a, the, to, and 등) / **비슷한 소리**(r/l, b/v 등) / **철자**
- 폰 입력이 번거로울 때를 위해 **빈칸 모드**를 둔다. 기능어만 빈칸으로 비우고, 후보 단어를 눌러서 채운다.
- 기록을 저장한다(SQLite): 콘텐츠별 정확도 → 진급 판단에 사용

### P4. 단어·표현장 + 복습 — 0.85 (3순위)
- 대본에서 단어를 길게 눌러 **단어 저장**, 문장 옆 ☆를 눌러 **문장 저장**
- 저장할 때 원래 오디오 구간을 함께 저장해서, 복습할 때 **소리로** 다시 듣게 한다.
- 받아쓰기에서 틀린 문장은 자동으로 저장한다.
- 복습은 FSRS 간격 반복 알고리즘으로 한다. 복습 시간이 되면 "들려주기 → 떠올리기 → 정답 확인 → 쉬움/어려움 평가".

### P5. YouTube 연동 (B) — 0.70 → 보완 후 0.75
**원칙**: 영상과 소리는 내려받지 않는다. YouTube 공식 플레이어를 앱 안에 넣어 재생하므로 약관상 허용되는 방식이다. 영상 정보와 자막은 **폰 안에만** 저장하고, 공개 저장소에는 올리지 않는다.

**흐름**
```
1) 앱에서 [YouTube 추가] → 영상 주소 붙여넣기
2) YouTube 앱·웹의 "스크립트 표시"에서 자막을 복사해 붙여넣기
   (시간이 붙은 자막을 앱이 문장 단위로 자동 분리)
3) 앱이 자막의 실제 말하기 속도(wpm)와 어휘 난이도로 단계 추정 → "약 L6" 표시
4) 이후는 TTS 콘텐츠와 같은 화면: 문장 반복, 대본, 받아쓰기, 단어장
```
**한국어 해석**: 앱 안에서는 무료로 번역할 방법이 없다. 그래서 공부할 영상의 자막을 Claude 세션에 보내면, 문장별 해석과 핵심 표현을 붙인 **학습 팩 파일**을 만들어 드리고, 앱에서 가져온다. 이 파일도 공개 저장소에는 올리지 않는다.

**제약 (사용자 확인 사항)**
- 인터넷이 필요하다.
- **화면이 켜져 있어야 재생된다.** YouTube 약관상 앱 안 플레이어의 백그라운드 재생은 안 된다. 그래서 이동 중에는 TTS 콘텐츠, 앉아서는 YouTube로 나눠 쓴다.
- 문장 단위로 끊을 때 오차가 약 0.2~0.3초 생길 수 있어서, 앞뒤로 여유 시간을 둔다.
- Windows에서는 앱 안 재생이 불안정할 수 있어서 **Android를 먼저** 만든다.

**보완**
- 이 작업 환경에서는 YouTube 접속이 막혀 있어서, 채널 내용을 제가 직접 확인할 수 없다. 영상 주소와 자막은 사용자가 보내 주는 것을 기준으로 한다.
- 구현 전에 시험(spike)을 한다: Android에서 앱 안 플레이어로 문장 구간 반복이 실용적인 정확도로 되는지 먼저 확인한다.

### P6. TTS 콘텐츠 확장 (C) — 0.75
| 문제 | 대책 |
|---|---|
| 양 부족 | 단계당 30개 이상 (L1~L5부터, 이후 L6~L10) |
| 너무 짧음 | **연재형 에피소드 2~5분**: 한 이야기가 여러 편으로 이어지는 형식. 같은 인물(Max 가족)이 계속 나온다. |
| 부자연스러운 음성 | ① 말하기 속도를 **0.85배 아래로 낮추지 않고**, 느린 단계는 문장 사이 쉬는 시간으로 조절한다. ② 화자마다 맞는 목소리를 다시 고른다. ③ 그래도 부족하면 유료 TTS를 검토한다(사용자 결정). |
| 주제 | Easy English 채널 영상에서 받은 주제와 말투를 참고해 **새로 쓴다** (복사·요약이 아니라 참고만) |

### P7. 일정 — 0.75
주당 테스트 1시간 기준으로, 마일스톤마다 APK 1개와 확인 목록을 드린다.
