# UI 디자인 방향 — "클래식 뮤직플레이어 감성"

> 상위 문서: [PLAN.md](./PLAN.md) · 버전 v0.2 · 2026-11-20

## 1. 원칙
1. **한 화면에 한 가지 일**: 목록 메뉴를 고르고 → 재생 화면으로 들어간다. 그게 전부다.
2. **휠로 조작**: 원형 휠 하나로 메뉴 이동, 문장 이동, 반복, 속도 조절을 모두 한다.
3. **흑백 + 강조색 하나**: 장식 없이, 촉감(햅틱)과 클릭음으로 손맛을 준다.
4. **오리지널 디자인**: 2000년대 휴대용 뮤직플레이어에서 *영감*만 받는다. 특정 회사의 로고, 상표, 제품 외형을 그대로 복제하지 않고, 휠의 비율·라벨·아이콘은 직접 디자인한다.

## 2. 화면 구조

```
┌───────────────────────┐
│  ▌ListenUp       ▮▮▮ │  ← 상단 바: 앱 이름, 오늘 학습 진행
│ ───────────────────── │
│  Today's Lesson     › │  ← 목록 메뉴. 선택된 줄만 강조색 띠
│  Levels             › │
│  Review (12)        › │
│  Progress           › │
│  Settings           › │
│                       │
├───────────────────────┤
│        ╭─────╮        │
│     ╭──  MENU ──╮     │
│     │ ⏮  ( ● )  ⏭ │     │  ← 원형 휠 (가운데 = 선택/재생)
│     ╰──   ↻   ──╯     │     하단 ↻ = 이 문장 다시
│        ╰─────╯        │
└───────────────────────┘
```

- **모바일**: 위 절반은 화면 패널, 아래 절반은 휠이다. 한 손 엄지로 조작한다.
- **데스크톱**: 기기 모양 레이아웃을 가운데에 고정 비율로 두거나, 넓은 화면에서는 왼쪽 패널 + 오른쪽 휠로 배치한다.
  - 마우스 스크롤 = 휠 회전, `Space` = 가운데, `Esc` = MENU, `←/→` = 이전/다음 문장, `R` = 다시 듣기

## 3. 휠 동작 매핑

| 입력 | 메뉴 화면 | 재생(학습) 화면 |
|---|---|---|
| 휠 회전 | 목록 위아래 이동 | 문장 단위로 앞뒤 이동 (회전 한 칸 = 한 문장) |
| 가운데 누르기 | 선택 | 재생/일시정지 |
| 가운데 길게 누르기 | — | **회전 모드 전환**: 문장 이동 ↔ 속도 조절(0.5x~1.5x) |
| MENU (위) | 뒤로 | 뒤로 (학습 중단 확인) |
| ⏮ / ⏭ (좌/우) | — | 이전/다음 문장 |
| ↻ (아래) | — | 현재 문장 다시 듣기 |

회전할 때마다 가벼운 햅틱(진동)과 "틱" 클릭음이 난다. 클릭음은 설정에서 끌 수 있다.

## 4. 주요 화면

**Now Listening (학습 화면)**
```
 L7 · Max's Field Trip         1.0x
 ─────────────────────────────────
           Sentence 3 of 18
   ▓▓▓▓▓▓▓░░░░░░░░░░░░░░  0:42
   [ 스크립트 숨김 — 휠 가운데 길게: 보기 ]
```

**받아쓰기**
- 데스크톱: 문장을 듣고 키보드로 입력 → `Enter` → 단어마다 정답(검정), 틀림(밑줄), 누락(빈칸 □)을 표시한다.
- 모바일: 기본은 키보드 입력이다. 대안으로 **휠 빈칸 모드**가 있다. 빈칸 위치에서 휠을 돌려 후보 단어를 고르는 방식이라, 연음·약화된 기능어를 훈련하는 데 특히 맞다.

**Progress**
- 현재 단계, 다음 진급까지 남은 조건(예: "85% 이상 2/3")
- 자주 놓치는 소리 TOP 5 (예: *to → tə*, flap T)

## 5. 비주얼 토큰 (초안)
| 토큰 | 라이트 (화이트 바디) | 다크 (블랙 바디) |
|---|---|---|
| 바디 | #F2F2F0 → #DCDCDA 그라데이션 | #1C1C1E → #0E0E10 |
| 화면 패널 | #FBFBF8, 안쪽 그림자 | #2A2A2C |
| 텍스트 | #111111 | #F0F0F0 |
| 강조(선택 띠) | #3A7BD5 계열 그라데이션 | 같은 색 |
| 휠 | #E6E6E4 / 가운데 버튼 #F7F7F5 | #2C2C2E / #3A3A3C |

- 서체: 영문 Inter, 한글 Pretendard (둘 다 오픈 라이선스)
- 애니메이션: 메뉴에 들어갈 때 화면이 좌우로 밀리며 전환(200ms). 그 외 효과는 최소화한다.
