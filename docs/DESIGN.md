# UI 디자인 — v0.5 (터치 중심, Material 3)

> 상위 문서: [PLAN.md](./PLAN.md) · 2026-11-21
> v0.3의 휠(다이얼) UI는 폐기했다. 사용 상황이 "폰, 이동 중"이라 한 손 엄지 조작을 기준으로 다시 설계했다.

## 1. 원칙
1. **조작은 아래에, 내용은 위에**: 재생 관련 버튼은 모두 화면 아래 독(dock)에 모은다. 엄지가 닿는 영역이다.
2. **한 화면에 한 가지 일**: 탭 3개(오늘 · 레벨 · YouTube) → 콘텐츠 → 학습 화면.
3. **차분한 중성 배경 + 강조색 하나**: Material 3, 인디고(#4F46E5) 기반 색 구성. 라이트·다크 모드는 기기 설정을 따른다.
4. **큰 글씨, 큰 버튼**: 재생 버튼 76dp, 나머지 버튼 48dp 이상. 대본은 17sp.

## 2. 화면 구조
```
하단 탭: [오늘] [레벨] [YouTube] [저장]

오늘     현재 레벨 카드 + 통계 3칸(연속 학습일 · 오늘 들은 시간 · 이 단계 완료)
         + "이어서 하기"(마지막 콘텐츠의 그 문장부터) + 콘텐츠 목록(진행 원형 / 완료 ✓)
저장     ☆로 저장한 문장. 누르면 원래 콘텐츠의 그 문장으로, 왼쪽으로 밀면 삭제
레벨     6개 구간(Little Ears … College)별 20단계 목록 → 단계 → 콘텐츠 목록
YouTube  [링크와 자막으로 추가] [학습 팩 파일 가져오기]
         영상별 카드(썸네일 · 챕터 수 · 해석 여부) 안에 챕터 목록, ⋮ = 해석 요청 복사/삭제

학습 화면
┌──────────────────────────────┐
│ ← 제목 / L1 · Daily · 0:24  [文A]│  ← 해석 켜기/끄기 (제목 줄 오른쪽)
│ (YouTube면 영상, 재생 불가 시 이유 표시)│
│ [듣기만] [문장] [대본] [표현] │  ← 텍스트 모드 (표현은 YouTube 팩만)
│      이전 문장 (흐리게)       │
│ ┌ 화자 ───────────── 3/11 ┐   │  ← "문장" 모드: 큰 카드
│ │ How are you?            │   │     영어 24sp, 구분선 아래 해석(강조색)
│ │ ─────────────           │   │
│ │ 기분 어때?              │   │
│ └─────────────────────────┘   │
│      다음 문장 (흐리게)       │  ← 누르면 그 문장 재생
│                              │
├──────────────────────────────┤
│ 문장 3 / 11  ⏸ 정지  [⟳ 2회·멈춤 1초]│  ← 반복 설정(누르면 설정 창)
│ ●──────○──────────────────── │  ← 문장 슬라이더 (끌어서 문장 이동)
│ [1.0x]  ⏮   ( ▶ )   ⏭   ↻   │  ← 속도 · 이전 · 재생 · 다음 · 다시
└──────────────────────────────┘
```

## 3. 조작
| 버튼 | 동작 |
|---|---|
| ▶ / ⏸ | 지금 문장부터 이어서 재생 / 일시정지 (끝까지 들은 뒤 누르면 처음부터) |
| ⏮ / ⏭ | 이전·다음 문장 한 개만 재생 (처음·마지막에서는 진동만) |
| ↻ | 지금 문장 다시 |
| 속도 | 누를 때마다 순환 (TTS 0.5·0.75·0.9·1.0·1.25 / YouTube 0.5·0.75·1.0·1.25) |
| 슬라이더 | 끄는 동안 문장 번호 미리보기, 손을 떼면 그 문장 재생 |
| 文A (제목 줄) | 해석 보이기/숨기기 (문장·대본 모드 공통) |
| 대본의 문장 | 그 문장 재생 (길게 누르면 ☆ 저장) |
| ☆ (문장 카드) | 이 문장 저장/취소 |
| 반복 설정 | 이어 듣기 때 문장마다 1·2·3·5회, 문장 사이 멈춤 없음·1·2·3초·문장만큼(따라 말하기). 설정은 기억됨 |

PC(Windows) 단축키: `Space` 재생 · `←/→` 문장 이동 · `R` 다시 · `S` 속도 · `T` 텍스트 모드 · `K` 해석

## 4. 텍스트 표시 규칙
- 영어: 문장 카드 24sp 굵게 / 대본 18sp. 해석: 강조색(카드) 또는 보조색(대본) 15~17sp
- 화자는 문장 위 작은 칩(현재 문장은 진한 칩). 이름이 길어도 잘리지 않음
- 현재 문장: 배경색 + 왼쪽 굵은 막대. 재생에 맞춰 대본이 자동 스크롤
