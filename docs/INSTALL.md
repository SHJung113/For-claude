# 설치 방법

## Android (폰에서 바로)
1. 폰 브라우저에서 아래 링크를 열거나 QR 코드를 찍는다. 항상 최신 빌드가 받아진다.
   **https://github.com/SHJung113/For-claude/releases/latest/download/listenup.apk**

   ![APK 다운로드 QR](./apk-qr.png)
2. 다운로드가 끝나면 알림에서 `listenup.apk`를 누른다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**(Chrome 등)을 켜고 뒤로 간다.
4. **설치**를 누른다. 업데이트할 때도 같은 방법으로 덮어서 설치하면 기록이 유지된다.
5. "Play 프로텍트" 경고가 나오면 **세부정보 더보기 → 무시하고 설치**를 누른다.

## Windows
1. **https://github.com/SHJung113/For-claude/releases/latest/download/listenup-windows.zip** 을 받는다.
2. 압축을 풀고 `listenup.exe`를 실행한다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누른다.

이전 빌드 목록: https://github.com/SHJung113/For-claude/releases
